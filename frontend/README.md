
# Delicias E-commerce
- Desarrollar una plataforma e-commerce fullstack que 
permita a los clientes comprar anticipadamente seleccionando la fecha y franja 
horaria exacta de retiro (en 1 minuto y sin hacer filas), y brinde al encargado de 
Delicias un Panel de Administración con Dashboard para controlar los cupos de 
horneado, planificar la producción diaria y agilizar la entrega en mostrador.
